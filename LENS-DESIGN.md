# Shared LENS design direction

Before changing this app’s visual design, read [the family master](../lens-design-system/MASTER.md), [shared tokens](../lens-design-system/tokens.css) and [this product’s design contract](../lens-design-system/products/imagelens.md).

Use the common theme, typography, interaction and accessibility rules while preserving this product’s distinct presentation and scanner behavior. The current LinkLens implementation is the reference. ImageLens 1.0.0 implements the teal gallery and inspector direction; see DESIGN-VALIDATION.md for evidence and limits.
