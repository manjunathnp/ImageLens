# ImageLens — Tech Book Store Demo

Open `index.html` in a browser to explore the captured ImageLens workflow and evidence. Keep the screenshots, assets, stylesheet, and script alongside it.

The screenshots and exported report come from a fresh UI-driven scan of `http://127.0.0.1:4400/techbookstore-shop.html`, the Tech Book Store public catalog. Scope: current page, desktop and mobile viewports. The run recorded 48 image observations, all passing the automated image checks, with evidence retained for broader review.

See `capture-provenance.json` for scan metadata, `capture-result.json` for the unchanged scan result, and `tech-book-store-report.html` for the self-contained export.
