# ImageLens — Tech Book Store Demo

Open index.html in a browser. Keep screenshots, assets, showcase.css and showcase.js alongside it. This is a standalone walkthrough, not a live scanner.

The screenshots and exported report come from a fresh UI-driven scan of `http://127.0.0.1:4400/techbookstore-shop.html`, the Tech Book Store public catalog. Scope: current page, desktop and mobile viewports. The run recorded 48 image observations, all passing the automated image checks. These passes do not establish accessibility conformance.

See capture-provenance.json for scan metadata and capture-result.json for the unchanged scan result. tech-book-store-report.html is the actual self-contained export. The older fixture-based video is not part of this updated demo.
