## Product Description

ImageLens is a standalone local web app for investigating image integrity and text alternatives. It helps quality engineers, developers, and web teams connect an image issue to the page, viewport, resource, and recorded markup behind it.

Choose the current page, all discovered pages, or a selected set. Review observations in a visual gallery or list, combine filters, and inspect loading evidence, alt attributes, accessible names, tooltips, dimensions, and overlapping findings. Captured previews make image review more visual; informative placeholders explain when a preview is unavailable.

The workflow ends with shareable HTML, PDF, CSV, or JSON reports. The self-contained HTML report supports category, issue type, page, viewport, and search filters, expandable evidence, and filtered CSV downloads.

ImageLens uses Node.js, Playwright, and Chromium. Browser sign-in is available in the local app. Discovery is bounded, mobile scans are viewport checks, and automated findings do not establish accessibility conformance. Text-alternative meaning and unsupported application states still need human review.
