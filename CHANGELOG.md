# Changelog

All notable changes to ImageLens are documented in this file.

## [1.0.0] - 2026-09-22

### Added

- Local-first browser workflow for public and signed-in image audits.
- Current-page, discovered-page, and selected-page audit scopes.
- Desktop and mobile viewport inspection with per-occurrence evidence.
- Image integrity, responsive candidate, text-alternative, tooltip, dimension, and contextual review checks.
- Visual image gallery, list view, combined filters, evidence inspector, and page coverage reporting.
- Interactive HTML, PDF, CSV, and JSON exports.
- System, light, and dark themes with responsive and keyboard-accessible UI behavior.
- Active-scan recovery, multi-tab history merging, cancellation, and storage-full handling.
- Scanner, interface, export, recovery, design-system, and accessibility regression suites.
